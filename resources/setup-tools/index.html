Setup Tools

Reference·Audience: New Integrator, Solution Builder, Fleet Operator·Read time: 3 min read

A reader out of the box has no Wi-Fi credentials and no broker target, so it cannot receive an MQTT command. No MQTT command sets the regulatory region at all, and Wi-Fi and endpoints can be set over MQTT only once a first connection exists. 123RFID Desktop (Windows 10 or 11, free from support.zebra.com) closes that gap out-of-band, over a direct USB-C cable.

Why a Bootstrap Tool Exists​

The reader cannot accept MQTT commands until it has a network path and an active endpoint pointing at your broker. That is a chicken-and-egg problem: you cannot configure the MQTT path over MQTT. 123RFID Desktop solves it out-of-band — you connect the sled to a Windows computer with a USB-C cable, set the essentials, and the reader comes online over Wi-Fi, or through a communication cradle for an RFD40 Standard. After that the computer is no longer in the path.

123RFID Desktop: What It Does​

Bootstrap step123RFID Desktop
Discover and attach the sledClick FIND READERS, connect over USB-C
Set the regulatory regionRegion tab → choose country → Apply
Configure Wi-FiCommunication → Wi-Fi → Scan and Choose Network
Configure the MDM endpointCommunication → End Point → New
Activate and verify the bootstrap connectionEnd Point Status → Activate → Refresh

The full step-by-step walkthrough with screenshots is Bootstrap a Reader with 123RFID Desktop.

123RFID Desktop is also the tool for generating encrypted (EDAT) firmware packages and for installing the WPA certificate on the reader.

What Does Not Change After Bootstrap​

Once the MDM endpoint is active and the sled is talking to your broker, the bootstrap tool is out of the loop. Everything you do from then on is plain MQTT:

  • The full MQTT command surface is identical across every sled.
  • Event semantics (heartBeatEVT, alerts, mqttConnEVT, dataEVT) are identical.
  • Topic structure (<tenantId>/<topic>/<deviceSerialNumber>) is identical.
  • Endpoint types (MGMT, MGMT_EVT, CTRL, DATA1, DATA2, MDM) are identical. DATA2 is currently not supported.
  • QoS settings, TLS and certificate management are identical.

Out of Scope​

  • The full bootstrap walkthrough (with screenshots): see Bootstrap a Reader with 123RFID Desktop.
  • Model identification by SKU label: see What You Need.
  • Many readers at once: see Provision Readers. Whether 123RFID Desktop can provision several readers in one session is not specified in the available sources.
