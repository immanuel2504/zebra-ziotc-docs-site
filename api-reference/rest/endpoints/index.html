Login

  • GET /cloud/localRestLogin Reader Login

App-led

  • GET /cloud/app-led Retrieves application LED state
  • PUT /cloud/app-led Updates application LED state

Stack-led

  • GET /cloud/stack-led Retrieves stack LED state
  • PUT /cloud/stack-led Updates stack LED state

Gpio

  • GET /cloud/gpo Retrieves the GPO status
  • PUT /cloud/gpo Updates GPO port state
  • GET /cloud/gpi Get GPI Status

Region

  • GET /cloud/region Retrieves reader region information
  • PUT /cloud/region Update region information
  • GET /cloud/supportedRegionList Retrieves the supported region list based on the reader type
  • GET /cloud/supportedStandardList Retrieves the standard channels of the supported regions

Control

  • GET /cloud/mode Retrieves the operating mode
  • PUT /cloud/mode Updates the reader's operating mode
  • PUT /cloud/start Start RFID Inventory or BLE scan
  • PUT /cloud/stop Stop RFID Inventory or BLE scan
  • GET /cloud/preSelection Returns whether the rxSawFilter is enabled or disabled
  • PUT /cloud/preSelection Enables or disables the rxSawFilter

System

  • GET /cloud/version Retrieves reader component version information
  • GET /cloud/status Retrieves reader operational statistics
  • GET /cloud/config Retrieves reader configuration
  • PUT /cloud/config Updates reader configuration
  • PUT /cloud/pass-through Pass-through command
  • PUT /cloud/cloudConfig Import cloud endpoint configuration
  • GET /cloud/readerCapabilities Retrieves the Reader Capabilities
  • GET /cloud/cableLossCompensation Retrieves the cableLossCompensation
  • PUT /cloud/cableLossCompensation Sets the cableLossCompensation
  • PUT /cloud/reboot Restarts reader
  • PUT /cloud/updatePassword Updates the local REST login password
  • GET /cloud/hostName Retrieves reader hostname
  • PUT /cloud/hostName Sets reader hostname

Logs

  • GET /cloud/logs Retrieves reader log configuration
  • PUT /cloud/logs Updates reader log configuration
  • GET /cloud/logs/syslog Retrieve Syslog
  • DELETE /cloud/logs/syslog Purge Log
  • GET /cloud/logs/RcLog Retrieve RcInfoLog
  • GET /cloud/logs/RgWarningLog Retrieve RgWarningLog
  • GET /cloud/logs/RgErrorLog Retrieve RgErrorLog
  • GET /cloud/logs/radioPacketLog Retrieve radioPacketLog
  • DELETE /cloud/logs/radioPacketLog Purge Log

Date&Time

  • GET /cloud/timeZone Retrieves the reader timezone
  • PUT /cloud/timeZone Sets the timezone
  • GET /cloud/ntpServer Retrieve the NTP server
  • PUT /cloud/ntpServer Set NTP server

Certificate

  • GET /cloud/certificates Retrieve installed certificate details
  • PUT /cloud/certificates Install certificate
  • PUT /cloud/certificates/{certname} Refresh certificate
  • DELETE /cloud/certificates/{certname} Delete certificate
  • GET /cloud/caCertificates List installed CA certificates
  • PUT /cloud/caCertificates/{caname} Install CA certificate
  • DELETE /cloud/caCertificates/{caname} Delete CA certificate

Network

  • GET /cloud/network Retrieves reader network configuration
  • PUT /cloud/network Updates reader network configuration
  • GET /cloud/wifiNetworks Retrieves available Wi-Fi networks
  • GET /cloud/networkInterfaces Retrieves network interfaces
  • GET /cloud/readPoints Gets the read points on the reader
  • GET /cloud/readerLocation Gets the GPS coordinates (lat/long)
  • GET /cloud/eSimConfig Gets the eSIM configuration
  • PUT /cloud/eSimConfig Sets the eSIM configuration

Firmware

  • PUT /cloud/os Updates OS software on device
  • PUT /cloud/revertbackOS Revert to previous OS version

userapp

  • PUT /cloud/apps/install Install user application
  • PUT /cloud/apps/{appname}/start Start user application
  • PUT /cloud/apps/{appname}/stop Stop user application
  • PUT /cloud/apps/{appname}/autostart Autostart user application
  • GET /cloud/apps List user applications
  • PUT /cloud/setdataToRG Set Data to RG
  • PUT /cloud/apps/{appname}/pass-through Send Request to Userapp
  • PUT /cloud/apps/{appname}/uninstall Uninstall User Application

Ble
